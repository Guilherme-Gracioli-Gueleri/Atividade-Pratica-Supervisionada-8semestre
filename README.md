# 🌱 RenovArte - Energias Renováveis

> O futuro é renovável. Projeto educativo sobre a importância, os tipos e os impactos das energias sustentáveis no planeta.

## 💻 Sobre o Projeto

O **RenovArte** é uma plataforma educativa interativa desenvolvida como Atividade Prática Supervisionada. O objetivo do site é conscientizar os usuários sobre a urgência da transição energética, explicando de forma didática e visual o que são energias renováveis, seus diferentes tipos (Solar, Eólica, Hidrelétrica, Biomassa e Geotérmica) e o impacto positivo que geram no meio ambiente e na sociedade.

## ✨ Funcionalidades

* **Dark/Light Mode:** Suporte nativo a temas, com persistência via `localStorage` e preferência do sistema.
* **Design Responsivo:** Interface fluida que se adapta desde telas de celulares até grandes monitores (Mobile First / Media Queries).
* **Animações de Scroll:** Elementos que surgem de forma suave à medida que o usuário rola a página, utilizando a API `IntersectionObserver` para alta performance.
* **Contadores Dinâmicos:** Estatísticas animadas utilizando `requestAnimationFrame`.
* **UI/UX Customizada:** Cursor personalizado (apenas para desktop), efeito *ripple* em botões e navegação com *smooth scroll*.
* **Acessibilidade (a11y):** Utilização de HTML semântico e tags ARIA para navegação acessível.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído puramente com tecnologias web nativas, focando em performance, sem a dependência de frameworks externos:

* **HTML5** (Semântico e Acessível)
* **CSS3** (Variáveis, Flexbox, Grid, Animações e BEM styling)
* **JavaScript (Vanilla ES6+)** (Arquitetura modularizada com IIFEs, DOM manipulation, Observers)
* **[Phosphor Icons](https://phosphoricons.com/)** (Biblioteca de ícones)
* **Google Fonts** (DM Serif Display e DM Sans)
